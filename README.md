# 🧠 AI Skin Disease Detection Chatbot (React + FastAPI)

## 📌 Overview
This project is a **text-based AI chatbot system** that predicts possible skin diseases based on user-described symptoms.  
It uses a **React frontend** and a **FastAPI backend**, with a structured disease database and intelligent matching logic.

---

## 🚀 Tech Stack

### Frontend
- React (Vite)
- Tailwind CSS
- Axios

### Backend
- FastAPI (Python)
- Uvicorn

### Core Logic
- Text preprocessing (normalization, synonyms)
- Keyword + fuzzy matching
- Confidence scoring system

---

## 🧠 Features

- 💬 Chat-based user interface
- 🧾 Symptom-based disease prediction
- 📊 Confidence score for predictions
- 🧠 Intelligent preprocessing (handles variations like "itch" → "itching")
- ⚡ Fast and lightweight system
- 🔌 API-based architecture (frontend ↔ backend)
